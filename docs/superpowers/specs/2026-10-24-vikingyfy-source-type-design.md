# VIKINGYFY 源码类型命名统一

## 目标

统一 VIKINGYFY 源码的正式 `SOURCE_TYPE` 值与代码命名，将旧值 `vwrt` 改为 `vikingyfy`。工作流输入、构建分支、自动检测、配置说明和测试都使用新名称。

## 行为与兼容性

- GitHub Actions 的源码类型选项、默认构建入口和脚本中的源码判断使用 `vikingyfy`。
- 自动识别非 Lean 源码树时返回 `vikingyfy`。
- 移除 `vwrt` 作为源码类型、别名、函数名或测试夹具名；旧的 `SOURCE_TYPE=vwrt` 调用不再受支持。
- VIKINGYFY 上游仍使用 `https://github.com/VIKINGYFY/immortalwrt`。根据设备回退到官方 ImmortalWrt 的行为与产物风味判定保持不变。
- `iwrt` 继续表示多个非 Lean 源码共用的配置家族；`VWrt` 作为仓库品牌保留。
- 实际源码风味元数据已经使用 `vikingyfy`，本次不改变产物命名规则。

## 涉及范围

- 更新 `.github/workflows` 中的可选值、分支条件、默认值和说明。
- 更新源码类型工具、无线配置函数及相关调用点。
- 更新 README 中的入口说明和配置示例。
- 更新受影响的测试输入、夹具、断言和变量名。
- 不重命名 `iwrt` 配置家族、配置文件名、工作流文件名或仓库品牌。

## 验证

- 运行源码类型工具测试及受影响的工作流、配置导出、元数据和无线配置测试。
- 检查活动文件中的旧源码类型值 `vwrt` 已清除，并确认保留的 `VWrt` 品牌和 `iwrt` 配置家族引用合理。
- 运行仓库脚本测试集，检查改名没有改变配置选择、仓库回退、包管理器、防火墙或产物元数据行为。
